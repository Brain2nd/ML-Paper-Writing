# ML Paper Writing

A Codex skill for drafting and revising machine learning papers, with section-level writing blueprints, sentence and paragraph guidance, and evidence reports based on published papers.

## Contents

- `SKILL.md`: skill instructions and writing guidance.
- `references/`: supporting analyses and examples used by the skill.

## Install

Copy this repository into your Codex skills directory as `ml-paper-writing`:

```sh
git clone https://github.com/Brain2nd/ML-Paper-Writing.git ~/.codex/skills/ml-paper-writing
```

The `SKILL.md` frontmatter declares the skill name and description.

## Origin
